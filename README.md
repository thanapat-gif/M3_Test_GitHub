# สอบปฏิบัติ GitHub ชั้น ม.3

 **คะแนนเต็ม 10 คะแนน**

## วิธีเริ่มสอบ

1. เปิดโฟลเดอร์ห้องของตัวเอง: [ม.3/1](3-1) · [ม.3/2](3-2) · [ม.3/3](3-3) · [ม.3/4](3-4) · [ม.3/5](3-5) · [ม.3/6](3-6)
2. เปิดไฟล์ที่ตรงกับ **เลขที่** ของตัวเอง
   - เลขที่ 5 → `05.txt`
   - เลขที่ 15 → `15.txt`
3. ทำตามโจทย์ในไฟล์ให้ครบทุกข้อ

##  ข้อกำหนด

- โจทย์ของแต่ละคน **ไม่เหมือนกัน** ทำเฉพาะภารกิจของตัวเองเท่านั้น
- ตั้งชื่อ repository ให้ตรงตามโจทย์ **ทุกตัวอักษร**
- ชื่อไฟล์รูปต้องเป็น **รหัสลับที่อยู่ในรูป** และยังเป็นนามสกุล `.png`
- **ห้ามแก้ไขรูป** ที่ดาวน์โหลดมา

## คำแนะนำ

- รูปที่ต้องดาวน์โหลดอยู่ในโฟลเดอร์ [files](files)
- ระวังชื่อไฟล์ซ้อนนามสกุล เช่น `abc12.png.png` ❌

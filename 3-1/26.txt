ภารกิจของ ม.3/1 เลขที่ 26
==============================

1) สร้าง repository ใหม่ ตั้งชื่อว่า

       peach-3-1-26

   และเลือกเป็น Public

2) ดาวน์โหลดรูปนี้จาก repository ของครู

       files/book.png

3) เปิดดูรูปที่ดาวน์โหลดมา ในรูปจะมี "รหัสลับ"
   ให้เปลี่ยนชื่อไฟล์รูปเป็นรหัสลับนั้น โดยนามสกุลยังเป็น .png เหมือนเดิม

       ตัวอย่าง: ถ้ารหัสลับคือ abc12
       ให้ตั้งชื่อไฟล์เป็น abc12.png

4) อัปโหลดรูปที่เปลี่ยนชื่อแล้ว ขึ้น repository ที่สร้างในข้อ 1
   แล้วกด Commit changes

5) ส่งลิงก์ repository ของตัวเองให้ครู
   ตัวอย่างลิงก์: https://github.com/ชื่อผู้ใช้/peach-3-1-26
